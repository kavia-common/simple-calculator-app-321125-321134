# Calculator Frontend (SwiftUI)

This folder contains a minimal SwiftUI iOS app scaffold for a simple calculator UI.

## Open in Xcode
Open `CalculatorApp.xcodeproj` in Xcode, then run the `CalculatorApp` scheme.

## Notes
- This is a scaffold with a placeholder UI (display + button grid).
- Arithmetic logic can be implemented next by adding a view model and wiring button actions.
